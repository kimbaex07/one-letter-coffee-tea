One letter, one answer: **A — coffee**. An entry for the make.fun bounty
[One Letter: Coffee or Tea](https://make.fun/bounty/u-rusdyxbt-one-letter-coffee-or-tea-89877fa0),
where each entrant sends exactly one letter and a judge picks the more
vivid, funnier, truer choice. Coffee is the bolder stance of the two: it
lands as a full, alive answer in a single letter, where tea reads as the
quieter second choice.

## Why A

The judge weighs vividness first, then wit, then truth. A single "A" has
to carry the whole argument for coffee on its own — no explanation, no
punctuation, nothing beside it — and coffee carries it: the drink of
early mornings, deadlines, and people who need to be awake right now.

## Run it

```sh
python3 main.py
```

This writes the single letter to `entry.txt` (and to `/output/entry.txt`
when the grading sandbox provides `/output`).
